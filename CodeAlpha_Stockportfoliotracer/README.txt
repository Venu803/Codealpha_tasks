Stock Portfolio Tracker – Python Project

About the Project
This project is a simple Stock Portfolio Tracker developed using Python. It allows the user to enter stock names and quantities, then calculates the total investment value based on predefined stock prices. The program helps users understand how much money they have invested in different stocks.

This project was completed as part of the CodeAlpha Python Programming Internship to practice basic Python programming and problem-solving skills.

How the Program Works
The program stores stock prices using a dictionary.
The user enters how many stocks they want to add.
For each stock, the user provides the stock name and quantity.
The program calculates the investment value using price multiplied by quantity.
All values are added to get the total investment.
Finally, the results are displayed on the screen and saved into a text file called portfolio.txt.

Features
Takes multiple stock inputs from the user
Uses predefined stock prices
Calculates total investment automatically
Displays results clearly
Saves output to a text file
Simple and easy to understand code

Concepts Used
Python basics
Dictionary
Loops
Conditional statements
User input and output

File handling

How to Run
Install Python on your system
Open the project folder in terminal or VS Code
Run the following command:

python stock_tracker.py

After running, the program will create a file named portfolio.txt containing the investment details.
