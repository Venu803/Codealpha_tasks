Basic Chatbot – Python Project

About the Project
This project is a simple rule-based chatbot developed using Python. The chatbot interacts with users through the command line and provides predefined responses to common messages such as greetings, questions, and exit commands.

This project was completed as Task 4 of the Python Programming Internship at CodeAlpha. The main objective is to practice Python fundamentals and understand how loops, functions, and conditional statements work together in a real-time interaction program.

How the Program Works
The chatbot continuously takes input from the user through the console.
It checks the input using if-elif conditions and returns a suitable reply.
The conversation runs inside a loop until the user types "bye", which stops the program.

Features
Responds to greetings like hello
Answers simple questions
Provides predefined replies
Runs continuously until the user exits
Simple and beginner-friendly design

Concepts Used
Python basics
Functions
If-elif-else statements
While loops
String handling
User input and output

How to Run
Make sure Python is installed on your system.
Open the project folder in terminal or VS Code.
Run the following command:

python chatbot.py

After running the program, type messages to chat with the bot. Type "bye" to exit the chatbot.
