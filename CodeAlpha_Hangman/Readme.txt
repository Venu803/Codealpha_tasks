Hangman Game (Python)

About the Project

This project is a simple text-based Hangman game developed using Python.
The game randomly selects a word, and the player tries to guess it one letter at a time within a limited number of attempts.
This project was created as part of a Python Programming Internship task to practice core Python concepts.

How the Game Works

A word is randomly chosen from a predefined list.
The word is displayed using blanks for each letter.
The player enters one letter per attempt.
If the guessed letter is correct, it appears in the correct position.
If the guess is wrong, the number of remaining attempts decreases.
The game ends when the player guesses the full word or runs out of attempts.

Technologies and Concepts Used

Python
Lists and strings
Loops
Conditional statements
Random module
Basic input and output

How to Run the Program

Make sure Python is installed on your system.
Download or clone this repository.
Open the terminal in the project folder.

Run the following command:

python hangman_game.py
